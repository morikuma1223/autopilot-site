Claude Code 業務自動化スキルテンプレート集 vol.1（8本）

Claude Code / Claude Cowork に置くだけで使える、日本の中小事業者・個人事業主向けの SKILL.md テンプレート 8 本です。

「毎回プロンプトを書き直している」「出力が安定しない」「事業の前提を毎回説明している」——この 3 つを、スキル化で一度に解決します。

収録スキル

スキルできること
日次売上レポート売上 CSV から前日比・目標比・売れ筋・打ち手まで
見積書ジェネレーターヒアリング → 明細・税計算・有効期限つき見積書と送付文
問い合わせ一次返信メール・LINE の問い合わせを分類し、返信ドラフトを作成
SNS 投稿量産1 テーマから X / Instagram / LINE / GBP の 1 週間分
SEO/AIO 記事ライターキーワード → 構成 → 本文 → FAQ → JSON-LD まで
議事録→タスク化文字起こしから決定事項・タスク・期限・次回議題
請求書リマインド未入金一覧から段階別（初回・2 回目・最終）の催促文
競合プレスリリース監視競合の動きを集めて要約し、脅威・機会・学びを整理

特長

  • 各スキル冒頭の「事業設定」に屋号・商品・口調を書くだけで、以降の出力が全部あなたの事業仕様になります
  • 「推測で埋めない」「実績を捏造しない」「法規制表現を避ける」といったガードレールを全スキルに内蔵
  • 手順・出力形式・禁止事項を明文化しているので、Claude のバージョンが変わっても挙動が安定します
  • すべて日本語・日本の商習慣（インボイス、消費税、支払期限）前提

こんな方に

  • 1 人〜数人で事業を回していて、事務作業を AI に任せたい
  • Claude Code / Cowork を導入したが、プロンプトが属人化している
  • スキルの書き方の「型」を、実際に動くサンプルで学びたい
