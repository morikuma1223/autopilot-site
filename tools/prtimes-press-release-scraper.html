PR TIMES Press Release Scraper (Japan)

Collect Japanese press releases from PR TIMES by keyword or company. Clean JSON (title, full body text, company, category, date, images) ready for LLM/RAG, media monitoring and competitor tracking. Pay only per release.

Apify Store で使う（無料枠あり）→

Collects Japanese press releases from PR TIMES — Japan's largest press-release distribution platform (100,000+ companies) — and returns them as clean, structured JSON. Built for media monitoring, competitor tracking, PR analytics and LLM / RAG datasets in Japanese.

What you get

For each press release:

FieldDescription
titleHeadline
company, companyIdPublishing company and its PR TIMES ID
publishedAt, modifiedAtISO 8601 timestamps (JST source)
categoryPR TIMES category (e.g. イベント, 商品サービス)
descriptionMeta description
bodyText, bodyLengthFull body text, paragraphs joined by newlines — ready to embed or summarize
images, ogImage, thumbnailImage URLs
url, releaseId, sourceCanonical URL, release ID and which input produced it

Input

  • Keywords — e.g. 生成AI, EC, SaaS. Returns the latest ~40 releases per keyword.
  • Company IDs — the number in https://prtimes.jp/main/html/searchrlp/company_id/XXXX. Paginates through the company's whole archive (newest first), so you can pull a competitor's full release history.
  • Release URLs — direct URLs if you already have them.
  • Published after — stop at releases older than this date (works best with Company IDs).
  • Fetch full body — turn off to only list title/URL/company/date (5× cheaper).

Pricing (pay per event)

You pay only for results:

  • Press release (full body) — one release with body text, category, images and metadata.
  • Press release (listing only) — title, URL, company and date only.

No subscription; the Apify free plan is enough to try it.

Use cases

  • Competitor monitoring — schedule the Actor daily with your competitors' company IDs and push new releases to Slack / Notion via Apify integrations.
  • Media & PR analytics — count releases per category / company over time.
  • Japanese LLM datasets — body text is normalized (no navigation, no scripts) so it drops straight into RAG pipelines or fine-tuning corpora.
  • Lead generation — find companies announcing funding, new offices or product launches in your niche.

Notes

  • Only publicly available pages are accessed, at low concurrency (default 4). Please respect PR TIMES' terms and each company's copyright when reusing the content.
  • Keyword search returns the latest ~40 results by design of the site; use company IDs for full archives.
  • Japanese-language support and other Japanese data sources (Qiita/Zenn tech articles, e-Stat statistics) are available from the same developer.

FAQ

Q. PR TIMES の企業IDはどこで分かりますか？

企業ページの URL（/main/html/searchrlp/company_id/XXXX）の XXXX が企業IDです。

Q. キーワード検索は何件取れますか？

PR TIMES のキーワード検索は最新約40件を返します。過去分も網羅したい場合は企業IDで取得してください。

Q. 商用利用できますか？

プレスリリースは報道・拡散を目的に公開されている情報ですが、取得したデータの利用は PR TIMES および各社の利用規約・著作権法の範囲でご利用ください。
